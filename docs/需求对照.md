# 需求对照表

> 对应 `demmand.md`（后端技术栈 + 系统提示词）与 `demmand_前端.md`（前端布局与接口）。

## 1. 后端技术栈

| 需求 | 实现 | 状态 |
|------|------|------|
| Spring Boot（Java 必选） | Spring Boot 3.4.1 / Java 17 | ✅ |
| LangChain4j RAG 框架 | 1.23.0：Tika Parser、递归 Splitter、OpenAI Embedding、Chroma Store | ✅ |
| 向量数据库 Chroma / Milvus | Chroma 0.5.15（Docker） | ✅ |
| 大模型 API / Ollama | OpenAI 兼容协议，支持百炼 Qwen、DeepSeek、Ollama、vLLM | ✅ |
| Apache Tika 文件解析 | `langchain4j-document-parser-apache-tika` | ✅ |
| LangChain4j 文本分片 | `DocumentSplitters.recursive(500, 80)` | ✅ |
| MySQL | JPA + MySQL 8.4，保存用户 / 文件 / 会话 / 消息 | ✅ |
| 本地磁盘存储 | `UPLOAD_DIR` + Docker volume | ✅ |
| RESTful 接口 | `/api/auth`、`/api/file`、`/api/chat` | ✅ |
| 公共 / 私有知识库 | `visibility` + `accessOwnerId` 元数据过滤 | ✅ |
| 用户与权限 | JWT + BCrypt，学生 / 管理员角色 | ✅ |

## 2. 功能与系统提示词

| 需求 | 实现 |
|------|------|
| 校园事务问答 | 公共知识库检索 + 系统提示词约束 |
| 文件上传、解析、向量入库 | 异步 Tika + 分片 + Embedding + Chroma |
| PDF / DOCX / PPT / PPTX / TXT / MD | 全部支持；不做 OCR |
| 文档总结 / 框架梳理 | `mode=summary` |
| 划重点 / 背诵提纲 | `mode=keypoints` |
| 知识点通俗讲解 | `mode=explain` |
| 基于文档出自测题（单选、简答） | `mode=quiz` |
| 多份资料整合 | `mode=integrate` |
| RAG 优先、禁止编造 | 无检索结果直接固定话术，不调用模型 |
| 预设 5 条固定话术 | 后端常量与系统提示词中逐字保留 |
| 防作业代写 | `GuardService` 前置拦截 + Prompt 约束 |
| 无关请求拒答 | 游戏 / 情感 / 时政 / 编程题等前置拦截 |
| 权限隔离 | JWT 用户 + Chroma `accessOwnerId` 过滤 + MySQL 二次校验 |
| 扫描件 / 加密文档提示 | 固定解析失败话术 |
| 多轮上下文 | MySQL 保存会话与消息，检索 query 做追问补全 |
